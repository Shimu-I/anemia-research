Beyond the Needle: Attention-Based Multimodal Deep Learning for Anemia Screening Through Ablation Studies and Comparative Benchmarking

Can three short smartphone recordings (fingertip video, palm video, nail photo) screen for anemia without a blood test? And how should they be combined?

The data

909 young adults, three recordings each

A public multimodal dataset (CC BY 4.0). Classes are heavily imbalanced: only 75 participants are Moderate, which makes that class very hard to learn.

Preprocessing

From raw recordings to model-ready inputs

Frames are sampled after trimming unstable start and end segments. The nail is located by skin-colour detection and cropped. Everything is resized to 224×224.

Results

What the experiments showed

The honest part

Negative results are results

No fusion design clearly beat a simple baseline. That is a real finding, and the thesis treats it carefully.

🧪

No component proved itself

Self-attention, BiLSTM and demographics showed no consistent gain. Six fair setups landed between 0.380 and 0.459 macro-F1, close to a logistic regression (0.407).

🚩

Caught a too-good result

One setup scored 0.67–0.69. It looked wrong (it classified every Mild case correctly and used different image folders), so it was flagged and excluded.

🏷️

Found a label error

72 of 909 labels in the binary label file were shifted by one row. It was documented and the three-class work used the corrected metadata.

🎲

Single runs mislead

Single-split results often contradicted five-fold ones, so conclusions rest on cross-validation.

Provisional best model: image-only, BiLSTM + self-attention. Macro-F1 0.459 ± 0.075, but it found only 1 of 7 Moderate cases. Not ready for clinical use.
Limits

What the evidence cannot say

One site, one phone

Participants aged 18–25 from a single location. No external validation.

Tiny test classes

Only 7 Moderate test participants, so one person moves recall by 14 points.

Weak statistics

Five folds cannot reach p < 0.0625, so no difference is statistically confirmed.
